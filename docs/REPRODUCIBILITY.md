# 环境与运行

## 安装

建议使用独立Python 3.10以上环境，并按设备安装PyTorch。本次CPU检查环境为
Python 3.9.23和PyTorch 2.8.0；研究训练使用PyTorch 2.8的CUDA环境。

```bash
pip install -r requirements.txt
# 需要以包形式导入时安装
pip install -e .
```

## 运行现有工具

```bash
python scripts/smoke.py
python -m unittest discover -s tests -v
python scripts/summarize_results.py
```

第一项检查模型、损失和梯度；第二项检查各模块的数值约定；第三项读取汇总数据，
输出主要方法差值、条件差值和配准结果。前两项使用合成张量，不需要真实数据或权重。

## 真实数据实验的准备

需要另外准备PPCNet数据、本地划分、冻结AE权重、先验权重及潜码统计。
仓库目前包含模型、采样和训练目标；数据预处理、训练调度及检查点管理脚本后续整理。
已完成实验的设置见`configs/prior.json`与`configs/conditional_comparison.json`。

数据处理采用以下约定：

- 本地原DRR为1024²，经992²连续裁剪和面积重采样至256²。当前公开数据卡写512²，
  运行前需要核对下载版本及相机矩阵。
- 输出为128³、2.75mm体素、352mm视野。网格中心来自两相机名义中心射线三角化，
  不用GT包围盒或GT质心确定中心。
- 同一次裁剪必须同步更新影像与矩阵。采样采用`align_corners=False`像素中心约定。
- 三臂使用715例拟合的标准化统计；历史DPR-R使用此前795例统计，分别固定。
- GT投影掩膜用于监督或诊断，不进入条件重建的推理输入。

## 划分与评价

原始划分为829/103/105。后期将829例训练侧拆为795例训练和34例选择。
独立先验使用715例拟合、80例内部验证，之后80例也参与条件训练。
AE的64例训练样本与80例内部验证有5例重叠。

每个条件扩散模型在固定5组初始与反向噪声下评分，按患者平均；五个推理种子与
多次独立训练分开记录。105例测试尚未做最终评价。

CUDA三线性反传在现有环境下存在非确定性，恢复随机流不保证参数逐位一致。
归档设备的型号与显存字段也有待核实，已有计时作为当时环境的运行记录。

更新仓库前可运行`python scripts/privacy_audit.py`，检查文件清单和敏感内容。
