# 首版可以复现到哪里

此版可在CPU运行：模型实例化和容量检查、投影／潜网格契约、AE与损失反传、
v转换和短时间表采样、理想桥恢复、宏Dice和漏检记账，以及汇总结果的数值复算。
核心函数／类体来自项目执行代码，来源和SHA列在code_provenance.json。
数据加载、私人路径、检查点查找和服务器运行助手未随代码复制。

不能仅靠本仓库复现：795例预处理、冻结64例AE训练、200k先验训练、完整150k条件训练、
34例真实标签重建和全部历史诊断。原因是数据与权重不分发、病例划分映射未公开，
且首次快照没有纳入原始训练调度／缓存生成驱动。不要将合成检查称完整复现。

数据适配必须自行取得许可，并核验：

- 本地历史原图1024²，992²连续裁剪后面积重采样至256²；当前公开卡写512²，版本关系未解决。
- 输出128³、间距2.75mm、视野352mm。中心来自两相机名义中心射线三角化；
  未用GT包围盒或GT质心构造网格，但仍依赖可用标定与成像中心。
- array顺序D=z/H=y/W=x；矩阵乘的是(x,y,z,1)，潜格到128格映射为4*i+1.5。
- image与matrix128必须配对裁剪；像素中心采用align_corners=False。
- 所有最终条件臂使用冻结715拟合统计，历史DPR-R使用历史795统计，不能混用。
- AE64例与prior-val有5例重叠；80例不是对整个表示管线完全未见。
- 五个推理种子并非五次独立训练。CUDA三线性反传不保证逐位确定性。
- 原设备归档型号与显存字段存在不一致，绝对计时不作为标准板卡可迁移承诺。
