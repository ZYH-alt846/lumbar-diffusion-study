# 必须保留的纠错记录

- 旧B的约57mm HD95属于评价错误，已撤回，不放入当前排行榜。
- v3崩坏包含潜表示来源错配，修正后的结果仍不能证明精修有优势。
- 不能把近天花板、不会再提高或多步收益为零写成理论结论。
- 潜变量梯度范数不等于参数更新支配程度，更不能直接推AdamW的20倍支配。
- 条件变化幅度AUC不等于有益方向。旧错误区域、旧权重和池化选择性诊断已被替代。
- 首跳0.77是输出差相对输入扰动的范数比；输入扰动本身仅为首步误差的0.1倍，
  不能写剩余误差向下一步传播77%。
- 二维辅助头硬Dice约0.46，不能写二维已学好；对三维也没有额外收益。
- v4确定性最佳0.826003略高于仅重编码0.824413；“两精修器都未超过”错误。
- 旧桥模型和新独立先验条件模型的donor结果必须分开，新模型联合条件效应明确存在。
- 体积分解按850个逐种子逐椎体行先计算再平均：当前14.5%／85.5%，
  旧先平均计数再分解的12.6%／87.4%不再使用。
- 总错误体素计数改善不必然提高宏Dice，不能把体素计数简单相减当成Dice机制。
- GT辅助对齐并不隔离上游原因，且不是可部署增益；比例不可与其他数值分解相加。
- 相同病例、AE、权重和损失下的多次失败不是多次独立否证。
