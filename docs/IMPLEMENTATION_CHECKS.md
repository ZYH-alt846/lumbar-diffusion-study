# 核心实现核对范围

首版在本地CPU完成了合成检查，没有读取真实病例或启动训练。
检查环境为Python 3.9.23、PyTorch 2.8.0 CPU；使用说明建议独立Python 3.10以上环境。

公开包与本地原执行模块在同一随机权重和合成输入下比较，以下最大绝对差全部为0：

- Small3DUNet输出。
- SubvoxelAE编码与解码。
- 双视图条件体提升。
- ConditionalDiffusion输出。
- 四时刻短表条件DDPM采样。

单独检查了v往返、桥过程理想恢复、条件／无条件采样一致、投影轴顺序与像素中心、
有效性掩膜、初始零注入、冻结参数梯度、标准化及解码决策、漏检记账和实际容量。
隐私检查另覆盖规则自检、路径与标识模式、暂存内容与工作副本不一致的场景。
本仓库的这些检查不代表已重跑GPU训练或全部1000步真实数据链。
