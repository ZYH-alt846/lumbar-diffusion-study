# 结果能说明什么

最终表与45个选点均来自同一34例内部选择队列。DPR-R是历史确定性参考，
不是扩散；CR是新的同条件确定性对照。预训练初始化与冻结自由度没有被单独隔离。

CD-F减CD-S的病例配对Dice差为-0.012229，95% bootstrap区间
[-0.019462,-0.004859]；减CR为-0.022127，区间[-0.030483,-0.012328]。
区间未校正长期开发和检查点选择影响，不能替代独立患者测试。

正确条件相对供体的+0.2436支持联合条件依赖，不支持“影像信息被充分利用”，
也不把旧BBDM的弱响应泛化到新模型。保存的供体数据仅为患者平均差值，原始
逐种子供体评分缺失，不能由现有文件重建全部供体评分链。

AE真值往返Dice0.955737、HD95 2.75mm。背景偏置4.45来自更早的64例训练校准，
当前AE从训练起固定此值。3.95/4.95与4.45相比往返Dice变化不足0.0005。
真值码和生成码可能不同分布，故这不是AE对任意生成码都无影响的证明。

条件输出169/170通过冻结解剖规则。规则有效性不是临床专家评分，也不保证患者
定位正确。CD-F的病例内5种子Dice标准差平均约0.00483；这与训练种子稳定性不同。

GT辅助平移把诊断差距0.036636降至0.023155；seed0刚体把其对应差距
0.036459降至0.013857。两种诊断样本口径不同，比例不能相加，也不能与体积
分解百分比相加。配准用GT、近邻重采样和表面ICP，不能作为部署方法成绩。

当前最具体的解释是：空间对齐差异是重要的可测误差环节。尚未定位它由冻结、
预训练、条件表征、损失还是优化引起。没有依据写“扩散不可行”或承诺换结构即可解决。

仍缺：跨来源患者身份去重、最终封存测试、独立训练重复、初始化／冻结的清晰干预、
真实X射线外部验证。若继续解释机制，最小候选是同先验初始化后全参数条件微调，
不同时更改损失、结构与采样器；本仓库没有执行这一候选。
