# 实验过程与每一步回答的问题

以下按研究推进顺序保留关键阶段。数字须按各自队列阅读；不能把早期 103 dev
与后期 34 select 混在同一排名，也不能把共享数据／权重的失败算成独立否证。

1. **接口与可学习性检查。** 核验标签编码／解码、影像与矩阵配对、坐标轴、
   梯度、标准化、采样端点和漏检处理。发现并修复过影像—矩阵来源不一致、
   流式标准差公式和训练／推理背景 logits 不一致。实现错误被独立于方法效果记录。
2. **六例训练内过拟合。** 确定性回归接近 AE 参考；epsilon 预测完整采样接近空白。
   v 参数化使采样 Dice 从约 0.0012 提高至约 0.87–0.90。该结果只是工程可学性，
   不能称新患者重建成绩。先前“7000步后不会再提高”的推断随后被额外预算对照撤回。
3. **全数据 A/B 和评价纠错。** 初始报告中 B 的约57mm HD95来自评价入口错误，
   修复后重新评价全部检查点；旧数值不作为当前证据。匹配更新预算后，在34选择集，
   A@20k/40k为0.8178/0.8208，B@20k/40k为0.7527/0.7833。
   更多预算帮助B，但没有追平A。一次固定的分割辅助损失对照也没有额外收益。
4. **单次读出与完整链。** 在早期103例开发复核，确定性A为0.8153，
   B单次读出0.8056，完整链0.7758。该开发集反复使用，且不是最终三臂队列。
   结论是这组权重的多步采样无收益，不能推广为多步扩散理论上无价值。
5. **A粗重建加桥精修。** 为避免修正器只见训练内优质粗预测，训练五个重新初始化的A，
   构造795例折外预测。初版确定性／桥精修在34选择集分别仅0.6814/0.3242。
   审计发现折外A与部署A的潜表示分布不一致，不能把这次灾难性结果简单归给扩散。
6. **统一重编码后重试。** 用“粗码→标签→同一AE重编码”统一输入，不用GT构造输入。
   原A0.820767，仅重编码0.824413，确定性精修0.826003，桥精修0.822182。
   崩坏消失；桥精修仍没有增益。此前“两个精修器都未超重编码”表述错误，
   确定性最佳点实际上有约0.0016微小增量，未达到继续投入条件。
7. **影像条件与二维辅助监督。** 加入二维编码与患者矩阵后，桥精修0.822178；
   错患者条件几乎无变化。二维辅助监督提高辅助头指标，但3D配对增量约
   -0.0004/-0.0001，没有重建收益。辅助头硬Dice约0.46，不能称二维问题已解决。
8. **自生成状态训练。** 固定父模型，比较标准桥态与50%自生成态，各追加5000步。
   完整链0.8212与0.8191，都低于不修正0.8244。总错误体素变化与宏Dice权重不同，
   不用“纠正数减破坏数”直接解释宏Dice。该局部精修路线随后关闭。
9. **独立三维先验。** 对真实标签AE编码训练无条件v预测先验，715拟合／80内部验证。
   200k后DDIM100原筛查覆盖72/80，未通过73/80门槛。固定权重采样诊断发现体积偏小；
   新声明的DDPM1000验证覆盖74/80，其他筛查项也通过。原失败保留，未事后改判。
   有限样本及采样配置边界仍在；不能写DDIM天然模式收缩。
10. **独立先验加联合条件适配。** 三臂各150k、795训练／34选择：CR0.8099、
    CD-S0.8000、CD-F0.7878，历史参考DPR-R0.8244。质量条件未过，
    但本人相对供体联合条件+0.2436，34/34正。新模型确实依赖联合条件，
    不能沿用旧桥模型“条件几乎无用”的结论。
11. **定量失效分析。** 逐种子逐椎体重算的Dice差距中，体积数值项约14.5%，
    重叠项约85.5%。旧的先汇总后分解曾得到12.6%／87.4%，已被替代。
    L1体积项很小，否定“体积缩小是主因”的叙事。
12. **稿件修订的现有数据诊断。** 补34例AE保真、偏置敏感性、病例配对及结构规则；
    GT辅助平移／seed0刚体使差距缩小36.8%／62.0%。这把问题收窄到空间对齐线索，
    没有隔离预训练、冻结、表示、损失和优化中的单一根因。没有追加训练或打开测试。

Swin-X2S曾做过Tiny/无预训练/低分辨率/100轮预算适配；它不是原论文主结果复现。
其历史开发成绩不拼接到最终34例表格。定位、扩散引导等更早探索的细节留在私有档案，
本快照不声称覆盖全部运行记录。
