# Code and data rights

This initial snapshot is supplied for private review. An open-source license for
the study's original implementation has not yet been selected. Public repository
visibility alone must not be described as an MIT, Apache, or other license grant.
The research team should confirm code ownership and third-party notices before
choosing a license and making a public release.

No external implementation repository is vendored here. The code provenance
file identifies local implementation symbols extracted into this package;
documents cite the methods that inspired them. That is not a claim of reproducing
official author implementations.

PPCNet and its VerSe/CTSpine1K source materials retain their own licenses. A code
license, if later selected, will not grant rights to those materials. Their
official access process must be followed. Real data, derived case-level codes,
masks and model checkpoints are deliberately outside this snapshot.
